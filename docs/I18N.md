# fxxkHilife 文案接口

当前页面文案位于 Flutter 模块，原生层只保留服务通知、系统入口和诊断日志需要的文案。

## 页面文案

页面代码位于：

```text
flutter_ui/lib/src/
```

Flutter 页面不直接读取 Android resource，也不调用原生 `I18n`。需要把文案抽离时，新增 Flutter 本地化资源和类型化文案 key；不要把页面文案重新塞回连接 Repository。

## 原生文案

原生入口：

```text
app/src/main/java/com/freebuds/controller/i18n/I18n.kt
```

它只服务于通知、Tile、服务和日志等原生流程。设备协议字段、页面展示文字和厂商 command id 不应混在同一个文案表中。

## 约束

1. 页面状态来自 `NativeSnapshot`，展示层只负责映射。
2. 原生服务文案继续使用 `I18n.t(...)`。
3. 新增语言时同时检查 Flutter 页面、通知和 Tile 三条路径。
4. 不恢复旧 Compose 的 `i18n()` 或 `CompositionLocal` 入口。
